How to Use / Best Practices:

  1. Choose a panel you would like to use, and place it where you would like it to be.
    1. Double click the panel to open up instance properties.
    2. Choose desired panel and mount colors (if applicable).
    3. Select if you would like to hide any of the optional components (like the mount, etc.). They will not disappear in the editor, but will disappear in Play Mode.
    4. Select what texture you would like to use for the panel. Again, this will only apply in Play Mode.
  2. Choose an operator you would like to add to the panel.
    1. On the left side of the Editor, check Add On Plane to be on.
    2. At the top left of the Editor, check Local to be on.
    3. Click anywhere on the panel's surface to perfectly place your operator at the correct angle on the panel.
    4. Use the XZ Position arrows to adjust the operator's position as needed. The operator should stay perfectly aligned with the panel during movement if the aforementioned Local transform setting is checked.
    5. Double click the operator to open up instance properties.
    6. (Optional) Give it a name. This may be tedious, but will keep your operators organized for easy editing and will greatly help if you run into any errors in Play Mode.
    7. Like the panel, choose any customization settings you would like for the operator. Operators also have a "Function" setting. Hover your cursor over any of the settings' options for details on what it does.
    8. If you get an error during Play Mode, read it carefully; you likely forgot to set the block option if using a Function other than "None". Otherwise, please report the bug if possible.
  3. Repeat Step 2 to fully build out your custom panel composition.

Play Sound on Action - Speaker Compatibility:

Some operators have a "Play Sound on Action" feature that allows you to play a sound on external SCO "speakers" when the operator is activated. The following details how different SCOs will affect the sound played on them.

Red's Speakers Pack:

  • This pack of speakers is recommended for use with this feature.
  • The location of the sound will be correct and aligned with the speaker.
  • You can edit various parameters of the speaker SCO to adjust the sound played on it, including:
    • Gain (Volume)
    • Range
    • Falloff
    • and Pitch

Any SCO:

  • Any SCO can technically be used as a "speaker".
  • The sound will play from the SCO's origin (wherever that is).
  • Default parameters will be used for sound properties (like Gain, etc.), and they cannot be changed.

Custom Tailored SCOs:

  • If you would like to create a custom speaker, you can do so easily.
  • The SCO's 3D object should have an element named "speaker". The sound will play from the origin of this element.
  • The SCO should have 4 double script parameters, with IDs: gain, range, falloff, and pitch. These respective properties will be honored if present.

No worries! Here's an easy break down to help you meet the requirements: 😊

  • First off, a great summary of what you can and can't do with the pack can be found here.
  • You are totally free to use this pack in any of your parks that you plan to share with other people (ie. Steam Workshop, forums, etc.)
    as long as you...
    • Keep the LICENSE file in-tact and present within the pack's files.
    • This includes when you package the park into a .nl2pkg file (however, the SCOs should automatically package it with them, so no worries about having to do it manually).
    • Crediting the pack and the author in your project or project's description is not technically required by the license, but is greatly appreciated.
  • The license requires that all source code must be disclosed and available. That technically means locked/encrypted .nl2pkg's break the license. However, I am willing to ignore this requirement as long as the pack and author are properly credited, visible outside of the locked package.
  • You may modify and improve any part of the pack you would like, as long as the license stays in-tact and changes remain available to the public. This includes locked/encrypted .nl2pkg's; meaning, no, modified works of this package are not allowed to be encrypted! If you have an addition you would like made to the original pack to be used in a private park, please feel free to contact me and I will gladly look into adding it.
  • Lastly, you can technically redistribute modified versions of this pack if you really want to, but I would much rather prefer you provide improvements to me so I can incorporate them into the official/original pack. You will be be credited too! I promise! 😉
